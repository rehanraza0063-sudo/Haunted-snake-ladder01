# Haunted Snakes & Ladders

A horror-themed Snakes & Ladders game in a single HTML file. No install, no backend, works offline.

## Run
Open `index.html` in a browser (or use VS Code Live Server). Click **Enter the Dark** to start so the audio can play.

## Features
- Two modes: **With Computer** (you vs 1-3 CPU players) and **Without Computer** (2-4 local human players)
- Up to 4 players
- Horror background music (drone, wind, heartbeats, screeches), generated with the Web Audio API
- Snake bite sound ("saaaanp") and ladder sound ("yeh"), also synthesized
- Rolling a 6 gives an extra turn; an exact roll is needed to land on 100
- Music and sound effects can be toggled separately

Controls: click **Roll Dice**, or press Space / Enter.
